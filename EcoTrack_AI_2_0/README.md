# EcoTrack AI 2.0

교육·연구용 자동차 배출가스 기준 비교 및 AI 분석 시제품입니다.

## 실행 방법
1. Python 3.10 이상 설치
2. 터미널에서 프로젝트 폴더로 이동
3. `pip install -r requirements.txt`
4. `streamlit run app.py`
5. 브라우저에서 표시되는 로컬 주소 접속

## GitHub / Streamlit Cloud 배포
- 저장소 루트에 `app.py`, `requirements.txt`, `data/` 폴더를 함께 업로드합니다.
- Streamlit Cloud에서 Main file path는 `app.py`로 지정합니다.

## 내장 데이터
- `data/inspection_unloaded_sample.csv`: 한국교통안전공단 무부하검사 샘플
- `data/in_use_emission_standards_sample.csv`: 한국교통안전공단 운행차 허용기준 샘플
- `data/manufacture_emission_standards_20261001.csv`: 국립환경과학원 제작차 허용기준 자료
- `data/training_template.csv`: 실제 검사 결과 라벨을 정리할 때 참고할 빈 템플릿

## 반드시 알아둘 점
- 내장 무부하검사 측정 데이터와 운행차 허용기준 샘플은 검사 방식이 일치하지 않습니다. 따라서 현재 내장 데이터만으로 무부하검사 결과의 법적 적합/부적합을 자동 판정하지 않습니다.
- 운행차 기준 샘플에는 ASM-Idling과 KD-147 기준이 포함되어 있습니다. 판정 화면은 검사방식, 연료, 차종, 제작일, 검사일이 일치하는 행을 찾고, 조건이 맞지 않으면 판정 불가로 처리합니다.
- 제작차 허용기준은 제작·인증 단계 기준이며 운행차 검사기준과 직접 혼용하지 않습니다.
- 내장 검사 데이터에는 검증된 적합/부적합 정답 라벨이 없으므로, 지도학습은 실제 결과 라벨이 포함된 추가 CSV가 있어야 합니다. 앱의 AI 학습 탭에 업로드하면 Random Forest를 학습하고 테스트 성능을 평가합니다.
- 화면에 표시되는 기준 비교는 교육용 참고이며, 법적 판정이나 행정처분을 대신하지 않습니다.
- 도로 원격측정(RSD) 데이터는 검사장 시험과 측정방법이 다르므로 별도의 기준·검증 절차 없이 직접 비교할 수 없습니다.

## 학습 CSV 예시 형식
`CO,HC,CO2,O2,NOx,검사결과`
- 검사결과는 실제 공식 검사결과(예: 적합/부적합)를 사용합니다.
- 측정방법과 단위가 서로 다른 자료를 한 파일에 섞지 않습니다.
- 위 예시의 값은 형식 설명용일 뿐 실제 학습 데이터가 아닙니다.
